# Department Ownership Map

| Section | Owner Agent | Accountable For |
|---------|-------------|-----------------|
| Company | Documentation Manager | Mission, roadmap, org chart, decisions, documentation policy |
| Engineering | CTO / Engineering | Architecture, API, database, AI modules, OBD, mobile, developer onboarding, versioning |
| Deployment & Infrastructure | Deployment Lead / Engineer | Compose stacks, hosted/prod topologies, backup, monitoring, deployment guides, per-instance secrets |
| Security | Security Officer | Security posture, secrets policy, incident runbooks, public-repo secret scan |
| Testing & QA | QA & User Testing | Test strategy, QA run logs, user testing results |
| Marketing & Website | CMO | Website, demo, social, growth |
| Finance | CFO | Budgets, costs, migration budget |
| Business Reviews | BDM | BDM weekly/monthly/quarterly/yearly reviews |

## Update Rule

Department owners must keep their Outline section and the matching `docs/` mirror pages current. If a doc is missing or stale, the Documentation Manager raises a Paperclip issue assigned to the owning department.
