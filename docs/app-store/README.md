## Description (short)
AutoBrain turns code + security readiness into one objective health score. Track vehicles, fuel, services, and track-day prep in one place.

## Description (long)
AutoBrain helps teams ship with confidence: an objective health + security read before you merge, plus a mobile surface for vehicle owners — fuel prices, service intervals, modifications, ownership advice, and track-day prep.

Features:
- Vehicle health score and readiness tracking
- Fuel price map and watchlist
- Service intervals and history
- Track mode with session live view, driver stats, prep checklist
- Ownership advisor and modifications log
