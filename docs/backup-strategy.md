# Backup Strategy

## What to back up

1. **PostgreSQL** — all app data.
2. **MinIO bucket** — receipts, photos, uploads.
3. **`.env`** — environment configuration (store separately, encrypted).

## Admin JSON backup (instant, in-app)

`GET /admin/backup` (admin-authenticated) downloads a full JSON snapshot of the database. `POST /admin/restore` wipes and restores from a backup file. The daily Celery beat task also writes a JSON backup to MinIO (`backups/`) with retention of `BACKUP_RETENTION_DAYS` (default 14).

Recommended cron (on the server):

```cron
30 2 * * * /opt/autobrain/scripts/backup.sh /backups && \
  find /backups -name "autobrain-backup-*" -mtime +14 -delete
```

## Restore

```bash
# Database
docker compose exec -T postgres psql -U autobrain -d autobrain < backup.sql

# MinIO
docker compose run --rm minio-init \
  sh -c "mc alias set local http://minio:9000 ... && mc mirror /local-restore local/autobrain-assets"
```

## Recovery objectives

- RPO: up to 24h (daily backup) or better with WAL archiving.
- RTO: ~15–30 min (restore + `docker compose up`).

## Notes

- Schedule valuation snapshots etc. are re-generated by Celery beat on restore.
- Keep a backup of the first working deploy so you can roll the whole stack back.
